# French opening and credits

Translates the startup credits and scrolling opening story while keeping the
stock fixed-width title-screen renderer and stock `$C1:0014` resource loader.
The component is independent from the intro/dialogue VWF components.

## Canonical inputs

- root `assets/opening_text.json`: clean-USA opening strings extracted from the
  stock compressed arrangement;
- root `translations/opening_text_french.json`: validated sparse French opening
  translations;
- `assets/opening_font.png`: editable 128×16, 32-tile opening font atlas.

Generated IPS/ROM/layout outputs are never inputs. `src/opening_hook.asm` is a
human-readable mirror of the 37-byte renderer helper generated by
`build_patch.py`; Python remains the executable source.

Opening IDs use the compressed source address plus deterministic decompressed
offset, for example `C7:B480+09F9`. The fifth French credit has no clean-USA
source position and uses `new:opening.credit.translation`.

## Runtime architecture

The builder decompresses the stock title code, arrangement and opening font,
regenerates the French data from the canonical inputs, then:

- patches decompressed title-code offset `$0845` to call the helper at
  `$EE:9000` while preserving the original instruction footprint;
- patches decompressed title-code offset `$2D8D` so the stock `$C1:0014`
  loader reads the relocated arrangement from `$EE:A000` instead of `$C7:B480`;
- redirects the startup-credit loop to an appended five-credit list and changes
  its visible dwell from 240 to 180 frames;
- recompresses title code and font into their original fixed-capacity blocks;
- serializes the rebuilt arrangement as a deterministic literal-only stock
  compression stream at `$EE:A000`.

The original arrangement block at `$C7:B480` is intentionally left untouched.
The literal-only stream avoids the old expensive optimal-LZ build path while
keeping the normal resource-loader/decompressor protocol. A direct raw copy to
WRAM was tested historically but conflicted at runtime with
`mana_tree_original`; do not restore that path without a concrete reason and
new combined runtime validation.

## Text and accent rules

The scrolling prologue keeps the validated overlay convention: `$7D` acute,
`$7E` grave and `$7F` circumflex. Accented E characters are stored as normal E
plus an accent tile on the row above. `$02` is a component-local compact marker
expanded by the helper to `e` + blank so the 13-record prologue remains exactly
332 bytes.

Startup credits use a dedicated one-cell `É` in opening-font tile `$7A` (the
former `Z` slot), because the scrolling overlay is unsuitable for the credit
fade. Literal `Z` is therefore rejected by the builder. This reservation is
local to the opening font and does not affect the shared French charset.

## Memory

- `$EE:9000-$9FFF`: reserved helper region; current helper is 37 bytes at
  `$EE:9000-$9024`.
- `$EE:A000-$BFFF`: relocated literal-only arrangement stream.
- WRAM `$7E:5000`: stock decompression destination; not private persistent state.
- `$EF`: deliberately unused by this component.

See `docs/MEMORY_MAP.md` and the root `docs/MEMORY_MAP.md` for the allocation
view shared with other components.

## Build

From the repository root:

```bash
python3 components/french_opening/build_patch.py \
  "Secret of Mana (USA).sfc" \
  -o /tmp/french_opening.ips
```

Optional `--layout` writes a generated prologue-layout report; `--patched-rom`
can emit a local test ROM. The builder validates the clean USA ROM, source
extraction, fixed-size prologue, compression round trips, allocation bounds and
IPS self-application.
