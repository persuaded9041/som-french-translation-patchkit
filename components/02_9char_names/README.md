# 02 - 9-character names + French accent row

Extends the Name Entry screen while preserving the original fixed-width renderer.

## Behavior

- Names can contain up to **9 characters** instead of 6.
- Four selectable rows are displayed:
  1. `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
  2. `abcdefghijklmnopqrstuvwxyz`
  3. digits / punctuation / symbols
  4. `Çàâçéèêëîïôùû`
- The cursor opens on the uppercase row and moves across all four rows.
- Blank cells on the accent row are encoded as `$80` spaces and count toward the 9-character limit.
- The lower French help text is bound by ROM-position IDs to the clean-USA
  `name_entry.help` rows in root `assets/interface_text.json`.

## Sources

- `assets/naming_characters.txt`: component-local four-row character grid.
- root `assets/interface_text.json`: clean-USA Name Entry help source.
- root `translations/interface_text_french.json`: sparse French translations for the validated help rows.
- `src/patch_data.py`: exact machine-code/data payloads consumed by the builder.
- `src/*.asm`: readable 65C816/data representation of the emitted changes.
- `docs/MEMORY_MAP.md`: ROM allocations and hooks.

Root source assets are regenerated from a clean USA ROM with
`tools/extract_text.py`. `build_patch.py` remains the executable source of truth;
it verifies the canonical source asset against the ROM and resolves the French
text by stable source ID before generating the patch.

## Component-specific charset constraint

Name Entry uses only `$D4-$E0` from the shared French charset. `$E1-$E5` remain
reserved by original Name Entry graphics, so this component deliberately does
not install them.

## Name Entry resource

The generated resource is relocated to `$E4:4000`:

```text
+$0000  uppercase row     60 bytes
+$003C  lowercase row     60 bytes
+$0078  symbols row       60 bytes
+$00B4  accent row        60 bytes
+$00F0  French help text  variable
+...    16 zero guard bytes
```

Each character row contains 30 two-byte cells. Framing and terminator cells are
generated by the builder; editable files contain only useful characters or
translations.
