# french_gfx memory map

No expanded-ROM or WRAM allocation is used.

| File range | SNES range | Size | Purpose |
|---|---|---:|---|
| `0x002116-0x002118` | `$C0:2116-$C0:2118` | 3 | Skip USA-only controller-palette override (`JSR $212F` -> `NOP NOP NOP`) |
| `0x12D8F0-0x12D92F` | `$D2:D8F0-$D2:D92F` | 64 | Shared 16×16 controller-button graphic, four 2bpp tiles |
| `0x12DBCC-0x12DBE3` | `$D2:DBCC-$D2:DBE3` | 24 | French X/A/Y/B button palette ramps (three BGR15 colors each) |
| `0x07FB20-0x07FB3F` | `$C7:FB20-$C7:FB3F` | 32 | West direction marker (`W` → `O`), one 4bpp tile |
| `0x128A00-0x128ABF` | `$D2:8A00-$D2:8ABF` | 192 | Two compressed HP indicators (`HP` → `PV`) |
| `0x129B40-0x129BFF` | `$D2:9B40-$D2:9BFF` | 192 | Two compressed MP indicators (`MP` → `PM`) |
| `0x12C420-0x12C47F` | `$D2:C420-$D2:C47F` | 96 | Compressed level indicator (`LVL` → `NIV`) |
| `0x1D1500-0x1D153F` | `$DD:1500-$DD:153F` | 64 | Alternate inn-sign tiles 0–1 |
| `0x1D1580-0x1D15BF` | `$DD:1580-$DD:15BF` | 64 | Alternate inn-sign tiles 2–3; the intervening range remains stock |
| `0x1F5460-0x1F54DF` | `$DF:5460-$DF:54DF` | 128 | Potos inn sign (`Inn` → `Aub`), four 4bpp tiles |

Standard checksum/complement bytes are also regenerated by the common ROM helper.

Runtime status: **validated**. All listed localized graphics were visually
validated in game; no per-screen hook or free-space allocation is required.
