# Extended player-name entry

Generic functional extension of Secret of Mana's Name Entry screen. This
component intentionally owns **no French translation or French glyph data**.

## Behavior

- Names can contain up to **9 characters** instead of 6.
- Exactly **three** selectable character rows:
  1. `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
  2. `abcdefghijklmnopqrstuvwxyz`
  3. digits / punctuation / stock symbols
- The cursor opens on the uppercase row and wraps across those three rows only.
- The relocated English help is extracted directly from the clean USA ROM at
  build time and adapted only where the functional extension requires it
  (`6 LETTERS` -> `9 LETTERS`; decorative quotes around `ATTACK` are omitted in
  the relocated copy).

A localization component may expand the generic three-row keyboard. The French
overlay `french_name_entry_extended` does exactly that: it changes the window
and navigation to four rows and adds its accented/extended row.

## Sources

- `assets/naming_characters.txt`: generic uppercase/lowercase/symbol rows.
- clean USA ROM: canonical source of the stock English Name Entry help; no JSON
  source is consulted for generic prose.
- `src/patch_data.py`: exact machine-code/data payloads consumed by the builder.
- `src/*.asm`: readable 65C816/data representation of the emitted changes.
- `docs/MEMORY_MAP.md`: ROM allocations and hooks.

## Resource layout

The generated generic resource is relocated to `$E4:4000`:

```text
+$0000  uppercase row       60 bytes
+$003C  lowercase row       60 bytes
+$0078  symbols row         60 bytes
+$00B4  English help        variable
+...    16 zero guard bytes
```

Each character row contains 30 two-byte cells. Framing and terminator cells are
generated by the builder; the editable file contains only useful generic
characters.

## Dependencies

None. This is the base Name Entry extension used by both
`french_name_entry_extended` and `name_entry_prefill`.
