# Compatibility audit

The five standalone IPS files were compared byte-for-byte against the clean US ROM.

## Functional overlaps

### GAME SELECT + intro VWF

This is the only intentional functional overlap.

- French accented font bytes at ROM `0x12DFF0-0x12E08B`: identical where both patches write them.
- ROM `0x0016F6`: different by design.
  - GAME SELECT standalone: `$E1` — `$D4-$E0` are direct accented glyphs.
  - intro VWF: `$E6` — `$D4-$E5` are direct French glyphs.
  - combined state: `$E6`.

The shared font write is not removed because both patches must remain independently usable.

## Header/checksum overlaps

Components that expand the ROM independently write ROM-size metadata and their own standalone checksum. Checksum bytes naturally differ because each standalone ROM has different content. The root combiner treats these bytes as build metadata and recalculates one final checksum after all selected patches are applied.

## Opening + intro VWF

The earlier collision at `$C7:4285` no longer exists. The opening helper now lives at CPU `$EE:9000` / ROM `0x2E9000`; `$C7:4285` is exclusively owned by the intro VWF renderer.

## Policy

- identical overlap: allowed only when required for standalone operation;
- checksum/header overlap: allowed and regenerated by the combiner;
- known decoder threshold overlap: explicitly resolved by the combiner;
- any other different overlap: build failure.
